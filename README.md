# Angry Bank Bot

Telegram-бот «копилка с карточками» для групп (aiogram 3, один файл `main.py`).

В группах бот отвечает на команды и на клики по кнопкам меню как reply — цитатой на исходное
сообщение (кроме админ-панели в ЛС, там это не нужно).

## Функционал

- В группе:
  - `/AngryOpen` — крутануть копилку (раз в 20 минут на игрока, кулдаун общий на все чаты), выпадает случайная карточка со звёздами редкости, сила прибавляется к общей силе игрока (одна на все чаты), деньги — к его балансу в этом чате. Есть шанс на ×2/×3 крутку (см. ниже).
  - `/AngryClass` — крутануть класс (раз в минуту, кулдаун общий на все чаты, стоит 30 монет), выпадает карточка класса — только сила, денег не даёт. Тоже может выпасть ×2/×3.
  - `/AngrySteal` или слово «кража» ответом на чужое сообщение — украсть монеты у автора этого сообщения (раз в 30 минут).
  - `/AngryInfo` — профиль игрока (см. «Профиль» ниже). Ответом на сообщение — профиль автора сообщения;
    `/AngryInfo @username` — профиль по нику; без аргументов — свой профиль.
  - `/AngryBattle` — сразиться со случайным мобом на энергии (см. ниже).
  - Аирдропы падают в чат сами по себе — см. «Аирдропы» ниже.
  - `/clancreate`, `/claninvite`, `/clandelete`, `/clanleft`, `/clantop`, `/clan` — кланы (см. ниже).
  - `/AngryTop` — топ чата: участники этого чата, отсортированные по их общей силе.
- В личных сообщениях:
  - `/whoami` — показывает твой Telegram ID, username и являешься ли ты админом бота.
  - Админ-панель (кто админ — см. «Админ бота» ниже): разделы «🐷 Копилка», «🎓 Класс» и «🐗 Мобы» —
    у каждого свой независимый набор, но одинаковая структура: список, добавление, изменение, удаление
    (фото → название → сила [→ деньги — у копилки и мобов] [→ звёзды → птица — у копилки и класса]).
    Плюс «🌐 Все группы» — список всех групп, где сейчас есть бот, кнопкой на каждую (супергруппы —
    прямая ссылка-переход, обычные группы — только ID по клику, у Telegram нет ссылок на них),
    «📣 Разослать рекламу» и «🎁 Запустить аирдроп» — ручной запуск тех же рассылок, что идут по
    таймеру (правила те же: аирдропы не уходят в группы меньше порога участников; на автоматический
    таймер ручной запуск не влияет — очередной цикл придёт по расписанию как обычно),
    «⚙️ Настройки» — правка игровых параметров (см. ниже).
  - Любое другое сообщение показывает отправителю его профиль (см. «Профиль» ниже).

### Настройки (админка → ⚙️ Настройки)

Игровые параметры не захардкожены — они лежат в таблице `settings` и правятся из админки.
Значение читается из кэша, который наполняется при старте (`load_settings`) и обновляется сразу
после сохранения, так что изменения применяются без перезапуска. Если параметра нет в БД,
используется значение по умолчанию из `SETTINGS_SPEC`.

| Раздел | Параметры |
|---|---|
| 🐷 Копилка | кулдаун крутки (20 мин) |
| 🎓 Класс | кулдаун крутки (1 мин), цена крутки (30 монет) |
| 🎁 Аирдропы | интервал появления (20 мин), время жизни дропа (5 мин), лимит дропов на игрока за цикл (3), минимум участников в группе (5) |
| ⚡ Энергия и бои | максимум энергии (100), восстановление 1⚡ (10 мин), кулдаун боя (5 мин), энергии за бой от/до (3/5) |
| 🎲 Множители круток | шанс ×2 (10%), шанс ×3 (5%) |

В скобках — значения по умолчанию; в админке рядом с изменённым параметром показывается, каким он
был изначально. Текст меню группы (`/start`) собирается на лету из этих же значений, поэтому
цифры в описании всегда совпадают с реальными.

### Админ бота

По умолчанию админом становится тот, кто первым написал боту. Правило одноразовое, поэтому если им
случайно стал посторонний, сменить его через бота было нельзя. Для этого есть константа
`ADMIN_USER_ID` в `main.py`: если она задана, бот при каждом старте прописывает этот ID в
`bot_state.admin_id`, перезаписывая то, что там лежало.

Свой ID можно узнать командой `/whoami` в ЛС бота — она же покажет, админ ты сейчас или нет.

### Профиль

Профиль в ЛС (по любому сообщению) и `/AngryInfo` в группе — один и тот же формат: фото и данные
лучшего выбитого **класса** (не копилки), сила (общая на все чаты), деньги (в ЛС — суммарно по всем
группам, по `/AngryInfo` — в том чате, где вызвана команда), токены 🐟 (общие на все чаты), энергия,
клан.

### Редкость карточек

Количество звёзд у карточки выбирает сам админ (кнопками) при добавлении или изменении карточки —
никакого текстового названия редкости нигде не показывается, только звёзды:

| Кнопка | Отображение |
|---|---|
| ⭐ | 1 звезда |
| ⭐⭐ | 2 звезды |
| ⭐⭐⭐ | 3 звезды |
| 🌈⭐⭐⭐ | 3 радужные звезды |
| ✨⭐⭐⭐ | 3 астральные звезды |

Звёзды — премиум-эмодзи Telegram (`<tg-emoji>`); пользователям без Premium автоматически показывается обычная ⭐️.

Астральные карточки — самая редкая категория: их тоже добавляет админ обычным способом, но при
обычной крутке `/AngryOpen` или `/AngryClass` они выпадают лишь с шансом **0.05%** (у всех остальных
карточек в пуле — равные шансы между собой на оставшиеся ~99.95%). Основной способ их получить —
аирдропы (см. ниже).

### Множители круток (×2 / ×3)

Каждая крутка копилки и класса может сработать несколько раз подряд:

| Множитель | Шанс |
|---|---|
| ×1 (обычная) | 85% |
| ✨ ×2 | 10% |
| 🔥 ×3 | 5% |

Карточки тянутся независимо (могут повторяться), сила и деньги суммируются, а лучшая карточка/класс
обновляется по каждой из них. Кулдаун ставится один, цена крутки класса тоже списывается один раз —
множитель это чистый бонус.

Результат приходит одним сообщением: при ×1 это фото с подписью, при ×2/×3 — альбом из 2–3 фото,
где в подписи к первому перечислены все выпавшие карточки и итоговая сумма (у альбомов Telegram
разрешает подпись только на первом элементе).

### Птица карточки

После названия карточки в скобках показывается значок птицы, которой принадлежит предмет — тоже
выбирается админом кнопками (5 цветов). У карточек, которым птицу ещё не назначили, по умолчанию 🔴.

### Кража монет (/AngrySteal)

Ответом «кража» или командой `/AngrySteal` на чужое сообщение можно попытаться украсть у автора монеты
(раз в 30 минут на вора). Три исхода:

| Исход | Шанс | Результат |
|---|---|---|
| 🥷 Удачная кража | 20% | ворует 10% монет жертвы |
| 🤏 Частично удачная кража | 50% | ворует 5% монет жертвы |
| 🚨 Неудачная кража | 30% | ничего не ворует и теряет 5% своих монет |

Нельзя красть у ботов, у самого себя и у игрока без денег в этом чате.

### Энергия и бои с мобами (/AngryBattle)

Энергия — глобальный ресурс игрока (как сила): максимум 100, восстанавливается 1 единица раз в
10 минут. Каждый бой тратит случайно 3–5 энергии и доступен раз в 5 минут (кулдаун общий на все чаты).

Моб для боя выбирается случайно из списка, который наполняет админ (раздел «🐗 Мобы» в админ-панели:
фото → название → сила → награда монет за убийство — та же структура, что у копилки/класса).

Шанс победы: если сила игрока ≥ силы моба — победа гарантирована (100%); если меньше — шанс равен
отношению сила игрока / сила моба (например, 40% от силы моба → 40% шанс победить). При победе игрок
получает награду моба монетами в баланс этого чата; при поражении — теряет только потраченную энергию.

### Аирдропы

Раз в 20 минут в каждом чате, где есть бот, падает один аирдроп (с разбросом 5–30 секунд между
чатами, чтобы не отправлять всё разом). Сообщение «Появился … аирдроп!» с кнопкой «🎁 Забрать» —
первый нажавший забирает его, дальше сообщение меняется на «Игрок X забрал … дроп!» со списком
добычи. Не забранный за 5 минут дроп исчезает сам.

Редкость дропа (падает ровно один тип за раз):

| Дроп | Шанс |
|---|---|
| 📦 Обычный | 1 к 2 |
| 🎁 Необычный | 1 к 5 |
| 💎 Редкий | 1 к 10 |
| 🔮 Эпический | 1 к 20 |
| 🌟 Легендарный | 1 к 100 |
| 🔥 Мифический | 1 к 300 |
| 🌌 Астральный | 1 к 1000 |

Внутри дропа независимо друг от друга «бросается» каждая возможная награда яруса (сила/деньги —
у всех, токены и шанс астральной карточки — с легендарного и выше); если не выпало ни одной —
гарантированно засчитывается награда с наибольшим шансом, чтобы дроп никогда не был пустым.
Астральная карточка из дропа берётся случайно из копилки или из класса, сразу применяется игроку
(даёт силу и — если из копилки — ещё и деньги) и обновляет его лучшую карточку/класс, если та круче
текущей.

Защита от абьюза через много групп:

- **Максимум 3 успешных клейма на игрока за 20-минутный цикл**, суммарно по всем чатам —
  четвёртая попытка в любом чате в этом цикле будет отклонена.
- **Дропы не приходят в группы меньше 5 участников** (боты не считаются). Telegram не отдаёт
  список всех участников — видны только админы, поэтому из общего числа вычитаются лишь
  боты-администраторы (включая самого бота); бот-неадмин в чужой группе в счёт всё же попадёт.
  Если Telegram не ответил на запрос числа участников, дроп всё равно отправляется — чтобы
  временный сбой API не отключал живые чаты.

### Токены 🐟

Токены — отдельная глобальная валюта (как сила), получить можно только с аирдропов легендарного
уровня и выше. Отображаются в профиле.

### Кланы

Клан — глобальная сущность (как и сила): один клан на игрока сразу для всех групп, где есть бот.

- `/clancreate Название` — фото клана прикладывается той же командой (подписью к фото); создаёт
  клан за 500 монет (списываются с баланса в том чате, где вызвана команда). Название должно
  быть уникальным (без учёта регистра).
- `/claninvite` в ответ на сообщение — приглашает автора этого сообщения (только создатель клана
  может звать; в чате появляется сообщение с кнопками «✅ Принять» / «❌ Отклонить», нажать
  может только приглашённый). Максимум 20 участников в клане.
- `/clandelete` — удаляет клан (только создатель); нужно отправить команду дважды подряд в течение
  минуты, иначе счётчик подтверждения сбрасывается.
- `/clanleft` — выйти из клана. Создателю недоступно, пока он не удалит клан.
- `/clantop` — топ 10 кланов по суммарной силе участников.
- `/clan` — информация о своём клане (фото, название, сила, состав N/20 по убыванию силы,
  у создателя корона 👑); `/clan Название` — посмотреть любой другой клан.

### Реферальная программа (1% создателю группы)

Когда бота добавляют в группу, бот определяет её создателя (`getChatAdministrators`) и молча
прибавляет ему 1% от всех монет, которые получают игроки в этой группе — прямо к его обычному
балансу монет в этой группе (без уведомлений на каждое начисление, без отдельного счётчика).
Если сразу написать создателю в ЛС не получилось (он не открывал бота) — уведомление о подключении
1% отправляется автоматически, как только он сам первый раз напишет боту.

Раз в 1 час бот дополнительно рассылает во все группы, где он состоит, промо-сообщение
«добавь бота в свою группу и получай 1%» с кнопкой — кнопка ведёт по диплинку `t.me/<бот>?start=referral`
в ЛС бота, где показывается краткая инструкция с кнопкой «➕ Добавить бота в группу»
(`t.me/<бот>?startgroup=...`, открывает нативный диалог выбора группы в Telegram).

### Debug-уведомления админу

Чтобы можно было проверить, что фоновые рассылки реально доходят, а не тихо падают, админ в ЛС
получает уведомление о каждой из них:

- Промо 1% (раз в час) — одним сообщением сводка по всем чатам сразу: ✅/❌ по каждому,
  с кликабельной ссылкой на отправленное сообщение (для супергрупп).
- Каждый аирдроп — отдельное сообщение сразу после отправки (или после неудачи), тоже со ссылкой.
- Уведомление создателю группы о подключении 1% — доставлено сразу / встало в очередь / доставлено
  отложенно, когда создатель сам написал боту.

Ссылка на сообщение в группе работает только для супергрупп (`t.me/c/...`) — у обычных небольших
групп в Telegram нет прямых ссылок на сообщения, там показывается только ID чата.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен DATABASE_URL=postgresql://... python main.py
```

Токен бота берётся из переменной окружения `BOT_TOKEN`, строка подключения к БД — из `DATABASE_URL`
(если переменные не заданы, используются значения по умолчанию, зашитые в `main.py`).

Данные хранятся в PostgreSQL — таблицы `bot_state`, `cards`, `class_cards`, `mobs`, `chat_profiles`, `players`,
`chat_owners`, `clans`, `clan_members`, `bot_chats`, `airdrops`, `settings`, создаются автоматически при первом запуске.
Сила, энергия, токены и лучшие карточки игрока хранятся в `players` (одна запись на пользователя, общая для
всех чатов), остальное (деньги, крутки, кулдауны копилки/класса/кражи) — в `chat_profiles`, отдельно для
каждого чата. Клан — тоже глобальная сущность (`clans` + `clan_members`).

## Список чатов бота

`bot_chats` — общий источник для всех рассылок (аирдропы, промо 1%). Она наполняется тремя путями:
при добавлении бота в группу (`my_chat_member`), при **любом** сообщении в группе (middleware — на
случай, если событие добавления потерялось или бот был в чате раньше) и разовым бэкфиллом из
`chat_owners` при старте. Удаляется запись при кике/выходе бота из чата.
