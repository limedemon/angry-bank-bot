# Angry Bank Bot

Telegram-бот «копилка с карточками» для групп (aiogram 3, один файл `main.py`).

## Функционал

- В группе:
  - `/AngryOpen` — крутануть копилку (раз в час на игрока), выпадает случайная карточка, сила и деньги прибавляются к профилю игрока в этом чате.
  - `/AngryTop` — топ чата по сумме силы.
- В личных сообщениях — админ-панель (доступна только тому, кто написал боту первым):
  - добавление карточек (фото → название → сила → деньги);
  - список карточек с удалением.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python main.py
```

Токен бота берётся из переменной окружения `BOT_TOKEN`.

Данные (карточки, профили игроков) хранятся в `data/db.json` рядом с `main.py`.
