# Angry Bank Bot

Telegram-бот «копилка с карточками» для групп (aiogram 3, один файл `main.py`).

## Функционал

- В группе:
  - `/AngryOpen` — крутануть копилку (раз в час на игрока), выпадает случайная карточка, сила и деньги прибавляются к профилю игрока в этом чате.
  - `/AngryTop` — топ чата по сумме силы.
- В личных сообщениях — админ-панель (доступна только тому, кто написал боту первым), раздел «🐷 Копилка»:
  - список карточек;
  - добавление карточки (фото → название → сила → деньги);
  - изменение карточки (выбор поля: фото / название / сила / деньги);
  - удаление карточки.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен DATABASE_URL=postgresql://... python main.py
```

Токен бота берётся из переменной окружения `BOT_TOKEN`, строка подключения к БД — из `DATABASE_URL`
(если переменные не заданы, используются значения по умолчанию, зашитые в `main.py`).

Данные (карточки, профили игроков) хранятся в PostgreSQL — таблицы `bot_state`, `cards`, `chat_profiles`,
создаются автоматически при первом запуске.
