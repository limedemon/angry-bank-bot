# Angry Bank Bot

Telegram-бот «копилка с карточками» для групп (aiogram 3, один файл `main.py`).

## Функционал

- В группе:
  - `/AngryOpen` — крутануть копилку (раз в час на игрока), выпадает случайная карточка со звёздами редкости, сила прибавляется к общей силе игрока (одна на все чаты), деньги — к его балансу в этом чате.
  - `/AngryClass` — крутануть класс (раз в 5 минут, стоит 10 монет), выпадает карточка класса — только сила, денег не даёт.
  - `/steal` или слово «кража» ответом на чужое сообщение — украсть монеты у автора этого сообщения (раз в 30 минут).
  - `/AngryTop` — топ чата: участники этого чата, отсортированные по их общей силе.
- В личных сообщениях:
  - Админ-панель (доступна только тому, кто написал боту первым): разделы «🐷 Копилка» и «🎓 Класс» — у каждого свой независимый набор карточек, но одинаковая структура: список, добавление (фото → название → сила [→ деньги — только у копилки] → звёзды → птица), изменение всех тех же полей, удаление.
  - Любое другое сообщение показывает отправителю его игровой профиль (сила — общая на все чаты; деньги/крутки — суммарно по всем группам).

### Редкость карточек

Количество звёзд у карточки выбирает сам админ (кнопками) при добавлении или изменении карточки —
никакого текстового названия редкости нигде не показывается, только звёзды:

| Кнопка | Отображение |
|---|---|
| ⭐ | 1 звезда |
| ⭐⭐ | 2 звезды |
| ⭐⭐⭐ | 3 звезды |
| 🌈⭐⭐⭐ | 3 радужные звезды |

Звёзды — премиум-эмодзи Telegram (`<tg-emoji>`); пользователям без Premium автоматически показывается обычная ⭐️.

### Птица карточки

После названия карточки в скобках показывается значок птицы, которой принадлежит предмет — тоже
выбирается админом кнопками (5 цветов). У карточек, которым птицу ещё не назначили, по умолчанию 🔴.

### Кража монет (/steal)

Ответом «кража» или командой `/steal` на чужое сообщение можно попытаться украсть у автора монеты
(раз в 30 минут на вора). Три исхода:

| Исход | Шанс | Результат |
|---|---|---|
| 🥷 Удачная кража | 20% | ворует 10% монет жертвы |
| 🤏 Частично удачная кража | 50% | ворует 5% монет жертвы |
| 🚨 Неудачная кража | 30% | ничего не ворует и теряет 5% своих монет |

Нельзя красть у ботов, у самого себя и у игрока без денег в этом чате.

### Реферальная программа (1% создателю группы)

Когда бота добавляют в группу, бот определяет её создателя (`getChatAdministrators`) и молча
прибавляет ему 1% от всех монет, которые получают игроки в этой группе — прямо к его обычному
балансу монет в этой группе (без уведомлений на каждое начисление, без отдельного счётчика).
Если сразу написать создателю в ЛС не получилось (он не открывал бота) — уведомление о подключении
1% отправляется автоматически, как только он сам первый раз напишет боту.

## Запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=ваш_токен DATABASE_URL=postgresql://... python main.py
```

Токен бота берётся из переменной окружения `BOT_TOKEN`, строка подключения к БД — из `DATABASE_URL`
(если переменные не заданы, используются значения по умолчанию, зашитые в `main.py`).

Данные (карточки, профили игроков) хранятся в PostgreSQL — таблицы `bot_state`, `cards`, `chat_profiles`,
`players`, создаются автоматически при первом запуске. Сила игрока хранится в `players` (одна запись
на пользователя, общая для всех чатов), остальное (деньги, крутки, кулдауны) — в `chat_profiles`,
отдельно для каждого чата.
